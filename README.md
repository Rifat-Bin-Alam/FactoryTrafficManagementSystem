# Factory Traffic Management System



A Smart Factory Traffic Management System developed using ASP.NET Core MVC and C#.



\## Overview



This project is designed to manage and simulate traffic within a factory environment, including vehicles, routes, traffic conditions, decision-making, and safety-related operations.



\## Technology Stack



\- C#

\- ASP.NET Core MVC

\- .NET

\- Entity Framework Core

\- SQL

\- HTML

\- CSS

\- JavaScript

\- Visual Studio



\## Architecture



The system follows a layered architecture with separation of responsibilities across:



\- Domain

\- Application

\- Infrastructure

\- Persistence

\- Traffic State and Safety Logic

\- Controller Simulation

\- Testing

\- MVC Controllers and Views



\## Features



\- Factory traffic management

\- Vehicle and route management

\- Traffic state monitoring

\- Traffic safety rules

\- Traffic controller simulation

\- Traffic decision-making

\- Database persistence

\- Web-based MVC interface

\- Automated testing
